# Contributing to AnyProtocol

Thanks for contributing to AnyProtocol. Please open an issue or discussion
before beginning substantial work so that the proposed change can be aligned
with the project direction.

## Development workflow

- Keep pull requests focused on one change.
- Add or update tests for behavior changes and bug fixes.
- Run `dotnet test AnyProtocol.slnx` before opening a pull request.
- Do not include secrets, generated binaries, or unrelated formatting changes.
